# v1.0.12

- 规则常规设置增加“HTTPS 与证书”：开关、选择、上传、自动申请及访问地址提示。
- 从规则进入申请会带入域名；保存签发配置后才能提交。成功签发且域名匹配的正式证书选入草稿，保存规则后生效。
- 应用证书增加“替换并应用”，保持证书 ID、规则绑定和轮换元数据；检查域名与有效期，热更新失败恢复旧证书。fnOS 来源只读。
- “域名与证书”整合证书库和自动申请；高级设置保留独立 DDNS、系统部署、日志等入口；外部推送和系统证书来源折叠展示。
- 全部下拉框改为 Base UI 组件，支持键盘、禁用选项和弹窗内定位。

验证：本地构建、后端回归测试、浏览器规则流程与组件下拉框检查。演示环境不执行云端签发或系统证书写入；本包未自动安装到 NAS。
